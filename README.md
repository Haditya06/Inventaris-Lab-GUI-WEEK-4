# Inventaris Lab GUI

Aplikasi manajemen inventaris laboratorium berbasis Java dengan antarmuka grafis (GUI). Project ini ditujukan untuk membantu proses pencatatan, pemantauan, dan pengelolaan barang lab secara lebih cepat, rapi, dan mudah digunakan.

## Fitur Utama

- Pencatatan data barang laboratorium
- Edit dan hapus data inventaris
- Pencarian barang berdasarkan nama atau kategori
- Monitoring stok barang
- Tampilan GUI yang sederhana dan mudah dipahami
- Cocok untuk kebutuhan lab sekolah, kampus, atau penelitian

## Teknologi

- Java
- Swing / Java GUI (jika digunakan dalam project)
- IDE seperti IntelliJ IDEA, NetBeans, atau Eclipse

## Persyaratan Sistem

- JDK 17 atau versi yang lebih baru
- IDE Java (IntelliJ IDEA / NetBeans / Eclipse)
- Git untuk proses clone repository

## Cara Menjalankan Project

1. Clone repository ini:
   ```bash
   git clone https://github.com/Haditya06/Inventaris-Lab-GUI-WEEK-4.git
   ```

2. Buka project ke IDE Java yang Anda gunakan.

3. Pastikan semua dependency sudah terunduh.

4. Cari class utama (`main` class) lalu jalankan aplikasi.

5. Jika project menggunakan Maven:
   ```bash
   mvn clean install
   mvn exec:java
   ```

6. Jika project menggunakan Gradle:
   ```bash
   ./gradlew build
   ./gradlew run
   ```
